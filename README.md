# Учебные проекты

Здесь я храню учебные работы из Т-Академии и ВМК: задания по аналитике и машинному обучению, проекты по deep learning и параллельным вычислениям.

Большая часть работ выполнена в формате Jupyter Notebook.

## Т-Академия — аналитика

Задания по трём основным темам:

* теория вероятностей и математическая статистика;
* A/B-тестирование;
* классическое машинное обучение.

В ноутбуках есть работа с распределениями случайных величин, t-критериями, p-value и мощностью статистических тестов, а также расчёт параметров A/B-экспериментов.

ML-часть включает KNN, линейную и логистическую регрессию, регуляризацию, решающие деревья, ансамбли и градиентный бустинг. Отдельные задания посвящены предобработке данных, классификации мошеннических операций и анализу важности признаков.

## Университет — Deep Learning

Учебные задания по PyTorch:

* обучение полносвязных нейронных сетей;
* трёхклассовая семантическая сегментация;
* Named Entity Recognition.

Для задачи NER использовались BiLSTM и transformer-модель. В проекте по сегментации реализована PSPNet-подобная архитектура, подготовка данных и расчёт метрик качества.

## Университет — распределённая обработка данных

Мини-система для распределённой обработки текстовых документов.

Клиент, менеджеры и воркеры взаимодействуют через RabbitMQ. В проекте реализованы:

* выбор ведущего менеджера;
* heartbeat-проверки;
* репликация данных;
* загрузка и поиск по текстовым документам;
* расчёт TF-IDF через MapReduce;
* поиск похожих документов.

## Курсовая работа

Курсовая работа посвящена распределённому обучению свёрточных нейронных сетей на GPU.

Для ResNet-152 на датасете Tiny-ImageNet-200 были реализованы и сравнены:

* Distributed Data Parallel;
* pipeline parallelism;
* tensor parallelism.

Эксперименты проводились на вычислительном узле МГУ-270. В проведённых тестах DDP показал лучшее масштабирование по времени, а pipeline- и tensor-подходы оказались сильнее зависимы от разбиения модели, числа микробатчей и затрат на обмен данными.
